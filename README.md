# Pong Game

A simple single-player Pong game developed as a mobile application prototype using MIT App Inventor.

## About

This project is a single-player version of the classic Pong game. The player controls a paddle to hit the ball and earn points.

The game uses a simple single-page interface where all game elements and controls are displayed on one screen.

## Features

* Single-player gameplay
* Ball and paddle interaction
* Start button to start the game
* Reset button to restart the game
* Sound On checkbox to enable or disable sound
* Score tracking
* Score increases when the player successfully hits the ball
* Game Over when the ball is missed
* Single-page user interface

## How to Play

1. Press **Start** to begin the game.
2. Control the paddle to hit the ball.
3. Each successful hit increases the score.
4. If the ball passes the paddle, the game ends.
5. Press **Reset** to start a new game.
6. Use the **Sound On** checkbox to enable or disable the game sound.
